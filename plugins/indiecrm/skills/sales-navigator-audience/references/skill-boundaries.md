# Skill ownership and overlap

| Skill                                            | Owns                                                                                                                                                                                     | Boundary / integration                                                                                                                                                                                                              |
| ------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| IndieCRM sales-navigator-audience (this package) | Two persisted MCP modes: verified 1–3 seed lookalike and filter interview; actual UI count after each change, exact source URL, revision-safe resume and separate collection preparation | Portable IndieCRM instructions and server tools; no local Mac paths or third-party skill installation required. Never invokes a provider just to design filters.                                                                    |
| sales-navigator-lead-search                      | The recorded profile → temporary individual lookup → broader audience method, plus optional requested collection/checkpoint/media workflows                                              | Its recorded filter values, sheet names and counts are examples. This package carries the demonstrated method and source-evidence rules itself. A Sheets handoff is optional and separately scoped; not implicit in a CRM audience. |
| indiecrm-sales-navigator-import                  | Preserve an already established Sales Navigator URL, import/collect/resume through supported Connect or CLI, verify destination and partial coverage                                     | Starts after audience design. A paired Connect action or import capability does not authorize launching a disallowed browser, inventing filters or importing before selection.                                                      |
| IndieCRM development skill                       | Source changes, CLI command/schema discovery, existing checkout/auth/checkpoints, image recovery and deployment verification                                                             | Development/runbook guidance; not a portable buyer-targeting algorithm. A local CLI is optional transport to the same MCP tools, not required to persist a draft.                                                                   |
| IndieCRM manage-crm (this package)               | Workspace/product identity, record reads/writes, activities and host/browser connection boundaries                                                                                       | Route audience design here; retain exact product IDs, scope, browser order and no-outreach rules. prepare_lead_search is planning context, not verified targeting.                                                                  |
| IndieCRM save-lead-research (this package)       | Save verified importable rows, actual normalized source digest, retry-safe batch IDs, managed media, backfill and completion verification                                                | Executes separately authorized persistence after audience and complete baseline checks. Completion materializes contacts/companies/list memberships; no pipeline deals.                                                             |

The preexisting app lookalike helper can read saved profile context and may call
an enrichment provider when context is missing. This MCP audience workflow does
not call that provider path and does not treat saved role/location guesses as a
verified audience. Tool/browser/source availability, native pairing, source login,
audience selection, saved drafts and actual imported leads are separate states.
