# IndieCRM

- For workspaces, pipelines, records and activities, follow [Manage CRM](../manage-crm/SKILL.md).
- For search criteria, live results and lookalike audiences, follow [Lead search](../sales-navigator-audience/SKILL.md). Sales Navigator is the source for that workflow.
- To save verified leads, follow [Save lead research](../save-lead-research/SKILL.md).

Continue with the selected workspace, product and saved search. During filter
selection, keep the result list visible beside the filters where supported.
While refreshing, label the last verified results with their previous filters.
After each applied change, show the active criteria and observed count compared
with the previous count. In Voice, mention matching examples when they help
choose the next filter. Check browser access in the current chat before
assuming a cloud chat has a browser.
